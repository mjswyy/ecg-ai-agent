## 发现清单

### 🔴-1 rebuild_ptbxl_reports.py 丢弃 split 字段、15110→21799，废掉 CLIP 防泄漏双保险
- **位置**：`scripts/rebuild_ptbxl_reports.py:27-28`
- **证据（confirmed）**：只写 report 字段、遍历整份 ptbxl_database.csv（21799 行）。当前 ptbxl_reports.json = 21799 条、每条仅 report 字段；备份 .mojibake_bak = 15110 条含 ['split','ecg_id','report','scp_codes','dx_codes']。extract_text_embeddings.py:74 依赖 reports[r].get('split','unknown')，重建后恒 'unknown'；train_ecg_text_clip.py:111 的红线检查随之永远告警且失效。
- **修法**：重建时保留 split 字段（从旧备份或当前 manifest 回填），仅输出实际使用的 15110 条。

### 🟠-1 患者级重划分未同步 text_embeddings/report_splits.json
- **位置**：`scripts/patient_level_split.py:66-88`（对照 `train_ecg_text_clip.py:111-112`）
- **证据（confirmed）**：patient_level_split 只写 manifest + ecgfounder_features。实测 15110 条 ptb-xl 报告中 6,102 条 ECG split ≠ report split（ECG=train 但 report=test 1,786 条、ECG=test 但 report=train 1,038 条）；train_ecg_text_clip 对这些只打 warning 不拦截。
- **修法**：重划分后同步重写 report_splits.json 与报告的 split 字段，或从当前 manifest 推导。

### 🟠-2 relabel_report 与磁盘现状漂移；patient_split_report.json 缺失
- **位置**：`outputs/relabel_official27/relabel_report.json` vs `data/physionet2020/processed_5k/*_manifest.json`
- **证据（confirmed）**：relabel_report 记录 26384/5687/5678（记录级），当前 manifest 30232/3763/3754（患者级）；patient_level_split.py:121 本应写 patient_split_report.json 但 outputs/patient_level/ 下缺失。
- **修法**：重跑 patient_level_split 生成报告；论文引用分布时用当前患者级口径。

### 🟠-3 train_multimodal_fair 的 C/C2 变体被 CLIP 门控误伤

- **修法**：C/C2（及可选的 D/D2）移出 clip 门控；更正 warning 文案。

### 🟠-4 train_ecgfounder_head best_state=None 边界崩溃
