## 发现清单

### 🔴-1 preprocess_data.py 按记录而非患者划分（患者级泄漏）
- **位置**：`scripts/preprocess_data.py:145-162`
- **证据（confirmed）**：对每个 source 直接 `rng.permutation` 在记录粒度切 70/15/15；ptb-xl 实测 2075 名患者有 >1 条记录，其中 1073 名患者的记录横跨 train/val/test（例：患者 ptbxl_p13619.0 的 8 条记录 HR00017/HR00020/HR00028 等在 test 与 train 同时出现）。
- **修法**：以 patient_id 为原子单元划分（ptb-xl 用官方 patient_id，其余源按记录归患者）。

### 🔴-2 processed 与 processed_5k 两套划分并存矛盾
- **位置**：`scripts/preprocess_data_5k.py:16,214-225,342`
- **证据（confirmed）**：processed = 30167/6462/6472（记录级 70/15/15），processed_5k = 30232/3763/3754（患者级 80/10/10）；15,411/37,749（40.8%）条记录在两个数据集处于不同划分，其中 4,492 条 processed-test 进入 5k-train、2,605 条 processed-train 进入 5k-test。磁盘状态由 patient_level_split.py 产生，而 preprocess_data_5k.py 仍声称"完全复用旧划分"。
- **修法**：统一划分来源；禁止跨数据集混用不同口径划分。

### 🔴-3 preprocess_data_5k.py 重跑会复制旧错误标签
- **位置**：`scripts/preprocess_data_5k.py:341`
- **证据（confirmed）**：`m["labels"] = old["labels"]` 复制旧 processed manifest 的 labels（旧版码-名错配产物）。对照当前 LabelExtractor：processed 42,618/43,101 条 labels 与官方映射不符（例：AF 记录旧 labels index 5=Q Wave Abnormal，正确应为 index 2=AF）；processed_5k 磁盘 37,749 条 labels 与官方映射 0 条不符（已修正）。重跑即回退。
- **修法**：labels 用当前 LabelExtractor.encode(dx_codes) 在线生成，不得复制旧值。

### 🟠-1 5,352 条无评分类记录被丢弃且孤儿 .npy 残留
- **位置**：`scripts/preprocess_data_5k.py:230-347`（与 `relabel_official_27.py:44-49`）
- **证据（confirmed）**：processed_5k 目录 .npy 文件 43,101 个，manifest 总条目仅 37,749；缺失 5,352 条 dx_codes 全是非 27 评分类代码。丢弃由 relabel 完成，preprocess 本身不说明。
- **修法**：文档显式声明"无评分类记录将被丢弃"，重跑后清理孤儿 .npy。

### 🟠-2 ECGDatasetForAgent 缺形状校验
- **位置**：`src/data_pipeline/dataset.py:288-300`
- **证据（suspected）**：仅做转置判断，无 else-raise；对比 ECGDataset（:119-125）与 ECGContrastiveDataset（:218-224）均有严格校验。(6, L) 信号会静默返回错误形状张量。
- **修法**：增加 `elif ndim!=2 or shape[0]!=12: raise ValueError`。

### 🟡-1 ECGDataset labels 可为空数组导致 (0,) 张量
- **位置**：`src/data_pipeline/dataset.py:146-153`
- **证据（suspected）**：无 labels 又无 dx_codes 时 `torch.from_numpy(np.array([]))` 产生 (0,) 张量，下游 BCE 崩溃。
- **修法**：回退全零 (num_classes,) 向量或显式抛错。

### 🟡-2 metadata_parser include_dx 死参数；-1.0 年龄哨兵离群
- **位置**：`src/data_pipeline/metadata_parser.py:134-151`
- **证据（suspected）**：include_dx 注释"尚未实现"；未知年龄 -1.0 与归一化区间 [0,~1.017] 不连续。
- **修法**：实现或删除参数；未知年龄置 0 + unknown 标志位。

### 🟡-3 loader rglob 同名记录静默取第一个
- **位置**：`src/data_pipeline/loader.py:221-237`
- **证据（suspected）**：record_id 取 stem 丢失子目录；裸名 rglob 命中即返回。当前数据 (source,record_id) 唯一无碰撞，属潜在缺陷。
- **修法**：record_id 保留相对子目录，或多候选时告警/抛错。

### 💡-1 时间扭曲 scale<1 两端常量平台（最长 20%）
- **位置**：`src/data_pipeline/augmentor.py:219-228`
- **证据（confirmed）**："内容居中承载"在两端用首/末采样点常量填充，scale=0.8 时平坦段达 20%，不完全等价于生理时间压缩。
- **修法**：边界反射/线性延拓或整段重采样+裁剪。

### 💡-2 official_zscore 对零填充区归一化为非零常量
- **位置**：`scripts/preprocess_data_5k.py:147-153`
- **证据（confirmed）**：实测短记录（9s，两侧 pad 250）pad 区为常量 -0.04608（std=0），非真零填充。影响 5k 中 48 条需填充记录。
- **修法**：归一化后把 pad 区显式置零。

### 💡-3 worker 种子复现性依赖调用方先 manual_seed
- **位置**：`src/data_pipeline/dataset.py:406-421`
- **证据（suspected）**：worker_seed 从 torch.initial_seed() 派生；未设主种子时每次运行增强序列不同，与注释"保证可复现性"不完全相符。
- **修法**：DataModule 提供显式 seed 并在 setup 时 manual_seed。
