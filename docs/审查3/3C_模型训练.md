## 发现清单

### 🟠-1 R 峰"全部 RR 被生理滤除"失败分支缺 insufficient 标志
- **位置**：`src/ecg_models/feature_extraction/r_peak_detector.py:85-126`
- **证据（confirmed）**：<2 峰分支（85-92）返回 insufficient=True；但"RR 间期全部被 300-2000ms 滤除"分支（113-115）只置 rhythm=insufficient_data，结果字典（117-126）无 insufficient 键。下游按 r.get('insufficient') 判断的消费方会把该失败误判为成功、静默接受 heart_rate=0.0。
- **修法**：所有失败/成功结果显式携带 'insufficient': bool。

### 🟡-1 频域 HRV 过滤后丢弃真实时间戳
- **位置**：`src/ecg_models/feature_extraction/hrv_analyzer.py:85,90-98`
- **证据（confirmed）**：rr 先生理过滤再判定时间戳长度；任一 RR 被滤除即 len(timestamps)≠len(rr)+1 → 真实 R 峰时间戳被丢弃，改用 0 起累计和被压缩时间轴插值。噪声 ECG 常见 → LF/HF 在错误时间基上计算。
- **修法**：用有效索引同步过滤 timestamps_ms 与 rr。

### 🟡-2 早停回填 best 权重后 val_thresholds 仍是最后一轮阈值
- **位置**：`src/ecg_models/trainer.py:367,382-398`
- **证据（suspected）**：每 epoch evaluate(fit_thresholds=True) 覆写 val_thresholds；best_state 快照与回填不含阈值 → 测试集评估用"最后一轮权重定的阈值"配"最佳权重"，口径失配（非泄漏）。
- **修法**：快照 best_state 时一并快照 val_thresholds，回填时同步。

### 🟡-3 HRV 数据不足返回全 0（与 QT 的 None 口径不一致）
- **位置**：`src/ecg_models/feature_extraction/hrv_analyzer.py:62,87,112,131,167-172; feature_bank.py:87`
- **证据（confirmed）**：HRV _empty_result/_time_domain 全 0（sdnn=0…）；QT 数据不足返回 None（to_vector 转 NaN）。0 与真实测量值无法区分，与 feature_bank 注释"缺失特征返回 NaN 而非静默填 0"矛盾。R 峰失败时 heart_rate=0.0 同样流入特征向量。
- **修法**：HRV 数据不足统一返回 None（或 to_vector 层对不足数据 NaN 编码）。

### 🟡-4 load_checkpoint 未用 safe_torch_load 且无 strict/key 前缀处理
- **位置**：`src/ecg_models/trainer.py:621-626`
- **证据（confirmed）**：torch.load 无 weights_only 参数（绕过仓库 safe_load.py 的 numpy 白名单）；load_state_dict 默认 strict=True 无前缀剥离，加载 'net.' 前缀检查点直接失败。实测 torch 2.7.1 下 weights_only=True 加载本项目检查点成功。
- **修法**：改用 safe_torch_load；state_dict 支持可选前缀剥离与 strict 参数。

### 🟡-5 磁盘检查点 best_metric 元数据恒 0.0（陈旧产物）
- **位置**：`src/ecg_models/trainer.py:603-618`; checkpoints/*/best_model.pt
- **证据（confirmed）**：5 个检查点全部 best_metric=0.0（outputs/best_model.pt epoch=0、xresnet1d_101 epoch=35、simclr_xresnet epoch=39、ecg_transformer epoch=29）——均为修复前产物。消费方读取会得到误导性 0。
- **修法**：重新生成检查点写入真实 best_metric，或文档标注旧检查点元数据不可信。

### 🟡-6 mAP 对无正样本类按 0 计入宏平均
- **位置**：`src/ecg_models/trainer.py:500-503`
- **证据（confirmed）**：27 类中仅 2 类含正样本时 mAP=0.0565 且对 25 个无正样本类各输出警告（宏平均按 0 计入）；与 macro_auc（455-458）显式跳过的口径不一致。
- **修法**：仅对 0<sum<len 的类别计算 AP 后取平均。

### 🟡-7 Net1D 无 feature_dim 接口（靠 dense→Identity workaround）
- **位置**：`src/ecg_models/backbone/ecgfounder_net1d.py:296-411; src/ecg_models/__init__.py`
- **证据（confirmed）**：Net1D 是带 150 类头的分类器，无 feature_dim 属性；ArrhythmiaClassifier.__init__:37 读 backbone.feature_dim 会 AttributeError；仅 ecgfounder_classifier.py:54 靠替换 dense 为 Identity 取 1024 维特征。文件含 matplotlib/optim/Counter 未用导入，未被 __init__ 导出。
- **修法**：Net1D 增加 feature_dim 属性 + return_features 标准出口；清理导入。

### 💡-1 标签平滑注释与公式不符
- **位置**：`src/ecg_models/trainer.py:300-303`
- **证据（confirmed）**：注释写"1→(1-s)，0→s"，实际 labels*(1-s)+0.5*s 得 1→1-0.5s、0→0.5s（标准二分类平滑公式，本身正确）。
- **修法**：修正注释。

### 💡-2 梯度噪声公式与注释不一致（缺 sqrt）；grad_clip=0 时噪声加在缩放梯度上
- **位置**：`src/ecg_models/trainer.py:336-344`
- **证据（suspected）**：注释称 noise_std = grad_noise * sqrt(eta_t)，代码无 sqrt；unscale_/clip 仅在 grad_clip>0 分支内。
- **修法**：统一公式与注释；噪声注入移到 unscale_ 之后。

### 💡-3 GradScaler 走 CUDA 回退分支触发 FutureWarning
- **位置**：`src/utils/device_utils.py:135-137`（经 trainer.py:77 触发）
- **证据（confirmed）**：CPU 下构造 ECGTrainer 即告警 torch.cuda.amp.GradScaler deprecated。
- **修法**：迁移 torch.amp.GradScaler/autocast（带 device_type）。

### 💡-4 sample_entropy O(N²) 且 B==0 误报 0 熵
- **位置**：`src/ecg_models/feature_extraction/hrv_analyzer.py:145-165`
- **证据（confirmed）**：双层循环 + 广播；range(N-template_len) 少取最后一个模板；B==0 直接返回 0.0（10 点噪声序列实测 sample_entropy=0.0）。
- **修法**：向量化；修正模板数；B==0 返回 None/insufficient。

### 💡-5 PositionalEncoding 超长序列静默截断
- **位置**：`src/ecg_models/backbone/transformer_encoder.py:50-52`
- **证据（suspected）**：超出 max_len(3000) 的部分加全 0 编码，无越界保护。L'=171 无影响，更长输入/更小 stride 会退化。
- **修法**：超长时告警或动态扩展缓冲区。

### 💡-6 xresnet1d docstring 与实现矛盾
- **位置**：`src/ecg_models/backbone/xresnet1d.py:7`
- **证据（confirmed）**：注释称"kernel_size=3 (not 1-3-1)"，实际复用 Bottleneck1D 正是 1×1→k×k→1×1。
- **修法**：修正注释。
