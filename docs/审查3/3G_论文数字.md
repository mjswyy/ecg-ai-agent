## 发现清单

### 🔴-1 论文三臂 rubric 的 main/report 分数（3.22/3.25 及三维分解）无法在磁盘复现
- **位置**：`paper/main.md:111,115`
- **证据（confirmed）**：当前 judge_rubric_results.json 仅含 kb_arm（3.123/2.831/2.769/4.108，与论文 kb 臂吻合）；main=3.22（2.91/2.80/4.15）与 report=3.25（2.89/2.85/4.17）在任何磁盘产物中均不存在。grep 全 outputs 无 3.22/2.91/4.15/2.89/2.85/4.17；历史产物 judge_rubric_results_all.json（main=2.962/report=3.038）与 prelitfl（main=3.12/report=3.241）均为过期的 133 条旧集分数。
- **修法**：重跑三臂 rejudge 写回完整文件，或撤回相关声明。

### 🔴-2 论文"决策层情境敏感性 100%"与磁盘实测 97.5% 矛盾
- **位置**：`paper/main.md:26；paper/related_work.md:154,159,160`
- **证据（confirmed）**：context_eval/metrics.json urgency_sensitivity_rate=0.975；main.md:126 自身写"97.5%（39/40）"、:177 写"97.5%"；"100% 敏感"出现在 §1.2 贡献表与 related_work 差异点——核心贡献声称与实测矛盾。
- **修法**：统一改为 97.5%（39/40）。

### 🟠-1 test_loader.py 四个用例全部假阳性（静默空跑仍"✅ 通过"）
- **位置**：`tests/test_loader.py:13-99`
- **证据（confirmed）**：四个用例依赖硬编码外部绝对路径 c:/Users/llyun/Desktop/ecg资料/classification-.../training（Test-Path=False）。实际运行输出 4 行 "SKIP: Raw data directory not found..." + "✅ All loader tests passed!"，期间 0 个 assert 被评估；pytest 下 return 被计 PASS 而非 skip。
- **修法**：改用 repo 内 fixtures；缺失数据时 pytest.skip/抛错而非 return；断言始终生效。

### 🟠-2 web_demo R 峰异常时向 HRV 喂伪造输入并显示 "HRV SDNN: 0 ms"
- **位置**：`web_demo/app.py:120`
- **证据（confirmed）**：detect 抛异常（r={"error":...} 无 rr_intervals）时，`r.get("rr_intervals", np.array([0.8]))` 把伪造 [0.8]（应为 ms 量级且仅 1 元素）喂给 HRV；len<3 返回全零；UI 静默显示 "HRV SDNN: 0 ms"——测量失败伪装成有效值。
- **修法**：r 含 error 时直接置 out["hrv"]={"error":...}，UI 显示"测量失败"。

### 🟡-1 论文内部 test 集大小自相矛盾（5,678 vs 3,754）

### 🟡-2 演示层/图表硬编码 "6,472 条"（重划分前旧数字）

### 🟡-3 web_demo docstring AUC 0.9214 与 UI/metrics 的 0.9456 矛盾
- **位置**：`web_demo/app.py:7 vs :239,:323`
- **证据（confirmed）**：同一文件三处 AUC（0.9214/0.9456/0.9456）互相矛盾；metrics.json=0.9456。
- **修法**：删除 docstring 硬编码或统一从 metrics.json 注入。

### 🟡-4 "350 来源"KB 规模声称无法溯源
- **位置**：`web_demo/app.py:8；paper/main.md:161；paper/related_work.md:161；scripts/make_figures.py:199`
- **证据（confirmed）**：实测 n_sources 和=306（+general=332）、source 条目=276（pubmed 241/litfl 27/ecgpedia 8）、唯一 doc_id=213、raw 文件=482——任何口径都得不到 350。
- **修法**：按明确口径（建议唯一来源文档数或 n_sources 总和）给出可复算数字并同步。

### 🟡-5 成绩单 0.850/94.8% 与磁盘唯一集成产物 0.8224/93.12% 不符；0.590/0.841/0.905 无产物
- **位置**：`paper/main.md:83`
- **证据（confirmed）**：comprehensive_eval.json "集成 Ensemble" macro_auc=0.8224、top5=0.9312；grep outputs/ 无 0.590/0.841/0.850/0.905 产物。
- **修法**：历史行统一标注来源版本或改为磁盘可复现值，补注产物路径或"无产物"。

### 🟡-6 web_demo HRV 展示未遵循"测量失败显式呈现"约定
- **位置**：`web_demo/app.py:237`
- **证据（confirmed）**：HR/QTc 均在 0/None 时显示"测量失败"，HRV 直接渲染 sdnn——空结果时页面显示 "HRV SDNN: 0 ms"。
- **修法**：HRV 增加"测量失败（RR 间期不足）"分支。

### 💡-1 LLM 自由文本未做 HTML 转义（gr.Markdown 注入风险）
- **位置**：`web_demo/app.py:299-305`
- **证据（suspected）**：仅 findings.name 经白名单过滤；evidence/rationale/actions 为 LLM 原文进 markdown。本机 127.0.0.1 风险有限。
- **修法**：对 LLM 文本转义，或启用 gr.Markdown sanitize。

### 💡-2 全局单例无并发保护
- **位置**：`web_demo/app.py:310`
- **证据（suspected）**：pipeline 为模块级单例，classifier/LLM 客户端/rcParams 跨请求共享；无锁/队列。单机单用户场景风险低。
- **修法**：加线程锁或按请求实例化重型组件。
