## 2. Phase 2 成果复述

| 模型 | test macro_auc | 参数量 | 训练平台 |
|------|:---:|------|------|
| InceptionTime（基线） | 0.590 | 291K | Ascend NPU 910B |
| xResNet1D-101 | 0.791 | 7.6M | Ascend NPU 910B |
| ECG Transformer | 0.808 | 6.5M | Ascend NPU 910B |
| **集成**（概率平均） | **0.822** | 14.1M | CPU 推理 |

**关键发现**：BCE + 强正则化（dropout 0.3, wd 1e-3, label_smoothing 0.1）优于 AsymmetricLoss；Transformer 需 FP32 训练；CNN + Transformer 异质架构集成有效。

## 5. 故障处理手册

| 症状 | 根因 | 修复 |
|------|------|------|
| Agent `classify_arrhythmia` 返回错误 | 未加载训练权重 | 见 P0.2 |
| `ECGTextCLIP` 报 `AttributeError: feature_dim` | SimpleECGProjector 缺少属性 | 见 P1.1 |
| xResNet 训练崩溃 | lr 过低或 ASL 冲突 | 改用 lr=5e-5 + BCE |
| Transformer 训练 NaN | AMP 溢出 | 改用 `--no-amp` |
| Transformer 训练慢 | CANN 8.0.0 未适配融合算子 | 手写 attention（已完成） |
| Notebook `/cache/` 数据丢失 | 重启后临时存储清空 | 用 moxing 从 OBS 重新同步 |
| GitHub 推送失败 | 代理问题 | 改用 obsutil 上传代码 |
