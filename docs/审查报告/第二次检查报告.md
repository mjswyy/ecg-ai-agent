## 2. 红线级发现清单（17 🔴 + 1 ❌，全部含文件:行号）

### 2A 数据管道（2 🔴）——**直接影响论文"官方基准"声明的成立性**

- **🔴-1 标签映射与官方评分类严重不符**（`src/data_pipeline/label_extractor.py:36-69, 77-102`）
  - 与官方 `dx_mapping_scored.csv` 逐码对比，至少 8 个规范码类名错配：`427084000`（官方窦速）被标为 "ST Elevation"；`427393009`（官方窦性心律不齐）被标为 "Sinus Tachycardia"；`17338001`（官方室早）被标为 "Ventricular Tachycardia"；`251146004`（官方低电压）被标为 IRBBB；`698252002`（官方 NSIVCB）被标为 LAFB；`10370003`（官方起搏心律）被标为 WPW；`164934002`/`59931005`（T 波异常/倒置）互换。
  - 约 9 个"类"（ST 抬高/压低、MI、缺血、WPW、II/III 度 AVB、RVH、VEB 等）根本不在官方 27 评分类内；等价表错配：`39732003`(LAD)→LBBB、`445118002`(LAnFB)→缺血、`713426002/713427006`(IRBBB/CRBBB)→MI、`164917005`(异常 Q 波)→LBBB、`47665007`(RAD)→MI。
  - **影响**：论文所有"27 类"数字（0.9192、Top-5、情境基准、Agent 评测）都建立在一套**自定义且部分错标**的分类体系上，"官方 27 类 SNOMED CT 基准"的说法不成立。**已由主报告作者独立复核确认（§4.1）。**

- **🔴-2 划分为记录级而非患者级，存在患者泄漏**（`scripts/preprocess_data.py:146-162`，5k 管线继承 `preprocess_data_5k.py:214-225`）
  - 用 `ptbxl_database.csv`（ecg_id→patient_id）与 processed_5k manifest 关联实测：**547 名患者同时出现在 train 与 test**（train 侧 834 条、test 侧 598 条记录的患者跨划分重复）、**73 名患者三划分全有**。**已由主报告作者独立复核确认（§4.2）。**
  - **影响**：PTB-XL 占测试集一半（3,277/6,472），患者泄漏系统性抬高总体 AUC 与"跨源泛化"叙事。

### 2B 模型训练（3 🔴）——**历史成绩单 F1 系统性高估**

- **🔴-1 `ECGTrainer.evaluate()` 在被评估集合上逐类 argmax-F1 定阈值**（`src/ecg_models/trainer.py:446-452`）
  - 波及 `train_backbone.py:194`、`train_simclr.py:175`、`train_ecgfounder_ft.py:133`、`eval_model.py:47`。实测同模型：val 阈值 F1=0.3786 vs 测试集阈值 F1=0.4048（**+6.9%**）。
  - **影响**：旧训练路径报告的 macro-F1 全部乐观；论文成绩单中从零训练模型的 F1（含 0.791/0.808/0.822 的 F1 列）不可信。
- **🔴-2 `eval_comprehensive.py` 在测试集现算 Youden 阈值评 F1 + bootstrap 无种子**（`:166-169`）——成绩单 0.791/0.808/0.822 的来源脚本，同款泄漏且 CI 不可复现。
- **🔴-3 `eval_ensemble.py` 在测试集逐类 argmax-F1 定阈值评 macro_f1**（`:90-95`）——同款问题。
- ✅ 独立复算确认：主协议 `train_ecgfounder_head.py`（val 定阈值 + best 权重回填）**正确**，0.9192/CI[0.9078,0.9295]/F1=0.3786 等数字逐位可复现——论文主数字本身不受此缺陷影响。

### 2C 对比学习与多模态（4 🔴）——**均为遗留栈必崩/失效，已标 DEPRECATED 但仍在审查面**

- **🔴-1 VQ-VAE perplexity 恒等于 1.0**（`src/context_modeling/ecg_tokenizer.py:54`）：`one_hot*log(one_hot+1e-10)` float32 下恒 0（1+1e-10 舍入为 1.0），且归一化错用 B 而非 B·L；实测随机输入 ppl 恒 1.0 而 codebook 实际用 15/16——监控指标完全失效。
- **🔴-2 VQ-VAE 编解码不对称**（`ecg_tokenizer.py:87-93`）：解码器 4 级 stride-2 上采样（×16）vs 编码器 3 级下采样（×8），decode 输出 8192 而输入 4096，forward 靠截半掩盖，每次重构丢弃一半输出。
- **🔴-3 `train_multimodal.py:79` 构造即崩**：`CrossAttentionFusion(..., nhead=8)` 参数名应为 `num_heads`，实测 TypeError，历史对照脚本无法运行。
- **🔴-4 `MetadataEncoder` age=None 时维度错配崩溃**（`metadata_encoder.py:49,65-75,93`）：特征维度 24≠MLP 输入 40，实测 RuntimeError（1×24 vs 40×128）。
