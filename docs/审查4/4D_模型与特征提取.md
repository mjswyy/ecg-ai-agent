## 发现清单

### 🟠-1 位置编码越界告警后仍崩溃（“显式告警”修复不完整）
- 位置：`src/ecg_models/backbone/transformer_encoder.py:53-60`
- 证据：`PositionalEncoding.forward` 在 `x.size(1) > self.pe.size(1)` 时仅 `logger.warning`，随后执行 `self.pe[:, :x.size(1), :]`——切片端越界会被 clamp 到 `max_len`，返回 `(1, max_len, d_model)`，与 `x`（`(B, L, d_model)`，`L > max_len`）在维度 1 广播失败。实测：
  ```
  pe = PositionalEncoding(d_model=64, max_len=100, dropout=0.0)
  x = torch.randn(2, 150, 64)
  → CRASH RuntimeError: The size of tensor a (150) must match the size of tensor b (100) at non-singleton dimension 1
  ```
  注释声称“旧版静默截断，超出部分位置编码为全 0”，但实际旧逻辑同样会崩——注释与事实不符，且“修复”只加了告警、没有真正容错。默认配置（`max_seq_len=3000`、`stride=24`、`kernel=49`）下，输入长度需约 >7.2 万采样点（≈360s@200Hz）才触发，属长程边界。
- 修法：`x + self.pe[:, :x.size(1), :]` 改为先做边界处理——超长部分显式补 0（`F.pad`）或直接抛带上下文的 `ValueError`（而非依赖广播误报的 RuntimeError）；至少让“告警”与“行为”一致。

### 🟠-2 HRV 频域“保留时间戳”修复被过滤长度比较击败 → LF/HF 失真
- 位置：`src/ecg_models/feature_extraction/hrv_analyzer.py:90-99`（后续回退在 105-113）
- 证据：先 `rr = rr[idx]` 过滤后，守卫条件用的是**已过滤后的** `len(rr)`：
  ```python
  valid = (rr > 300) & (rr < 2000); idx = np.where(valid)[0]; rr = rr[idx]
  if timestamps_ms is not None and len(timestamps_ms) == len(rr) + 1:   # N+1 vs M+1
      timestamps_ms = timestamps_ms[idx]
  elif timestamps_ms is not None and len(timestamps_ms) == len(rr):      # N+1 vs M
      timestamps_ms = timestamps_ms[idx]
  else:
      timestamps_ms = None
  ```
  时间戳长度为 `N+1`（R 峰数），过滤后 RR 长度为 `M ≤ N`。两分支分别要求 `N+1 == M+1`（仅当 `M==N`，即**无任何间期被过滤**时成立）与 `N+1 == M`（不可能）。实测（10 个间期、1 个异常）：
  ```
  after filter len(rr)= 9 len(ts)= 11
  branch N+1 check: False ; branch N check: False   → timestamps_ms 被置 None
  ```
  即：只要有任何 RR 被生理过滤（早搏/伪差，恰恰是该修复要处理的场景），时间戳被丢弃，回退到 `t = cumsum(rr)` 的“压缩时间轴”插值，频域 LF/HF 功率分布被系统性扭曲。
- 修法：过滤前先缓存 `n_orig = len(rr)`，用 `len(timestamps_ms) == n_orig + 1`（或 `== n_orig`）判断分支；再 `timestamps_ms = timestamps_ms[idx]`（`N+1` 对齐时 `idx` 对 `rr[:-1]` 起点，注意 `N+1↔N` 语义）。

### 🟠-3 QT 分析只捕获 ImportError，其它 neurokit2 异常击穿整条特征管道
- 位置：`src/ecg_models/feature_extraction/qt_analyzer.py:57-87`
- 证据：`try/except ImportError` 只兜住“neurokit2 未安装”。`nk.ecg_delineate` 内部可抛其它异常（如 NaN/导联脱落信号触发 `signal_period` 的 `int(nan)`）。实测：
  ```
  sig_nan = np.full(5000, np.nan); rpeaks=[1000,1500,2000]
  QTAnalyzer().analyze(sig_nan, rpeaks, 500, 'Male')
  → CRASH ValueError: cannot convert float NaN to integer
  ```
  该异常未捕获，直接击穿 `QTAnalyzer.analyze`，进而击穿 `FeatureBank.extract_all`（无任何特征产出）。NaN/导联脱落是真实 ECG 常见情况，属特定输入触发的整链路崩溃。
- 修法：`except ImportError` 扩展为 `except (ImportError, ValueError, TypeError, RuntimeError, IndexError)` 等，失败时 `logger.warning` + 回退到 `_simple_delineate` 或直接返回 `_empty_result`（与“失败显式化”口径一致）。

### 🟠-4 `heart_rate` 键冲突：QT 失败把 R 峰检测得到的有效心率覆盖为 None
- 位置：`src/ecg_models/feature_extraction/feature_bank.py:69`（初值）与 `:94-97`（`features.update(qt_result)`）；`qt_analyzer.py:131`（成功路径 heart_rate）与 `:205`（`_empty_result` 的 `"heart_rate": None`）
- 证据：`extract_all` 先写入 R 峰检测的 `heart_rate`，随后无条件 `features.update(qt_result)`；`QTAnalyzer._empty_result()` 与 `_compute_results()` 都携带 `heart_rate` 键。QT 描述失败时 `heart_rate` 被置 `None`，把有效测量覆盖掉。实测（合成 ECG，心率 72.3）：
  ```
  RPeak heart_rate = 72.3
  QT result heart_rate = None (error=insufficient_data)
  FeatureBank final heart_rate = None   ← 72.3 被覆盖丢失
  ```
  `to_vector` 中 None → NaN，LLM 收到的是一份被降级为“缺失”的生命体征（而非错误值，故定 🟠）；成功路径下 `heart_rate` 也改由 QT 的“中位数 RR”口径重算，与 R 峰的“均值 RR”口径不一致。
- 修法：QT 结果不应输出 `heart_rate` 键（或改名 `qt_heart_rate`），由 R 峰检测统一负责心率；`_empty_result` 删除 `heart_rate`，避免同名键跨模块覆盖。

### 🟠-5 QT 简单回退法输出固定伪造测量值（违反“严禁伪造测量值”）
- 位置：`src/ecg_models/feature_extraction/qt_analyzer.py:185-196`
- 证据：`_simple_delineate` 用固定窗口（`qrs_w=0.10fs`、`qt_w=0.44fs`、PR=`0.20fs`），对所有信号返回**常量**：QRS=100ms、PR=200ms、QT=490ms（仅首尾采样点截断时略有偏差）。实测两个完全不同信号：
  ```
  fallback ecg1 qt/qrs/pr: [490.0, 100.0, 200.0]
  fallback ecg2 qt/qrs/pr: [490.0, 100.0, 200.0]
  ```
  这些常量与信号内容无关，是伪造测量值，会以“QRS=100ms、PR=200ms、QT=490ms”注入 LLM。当前环境 neurokit2 已安装（0.2.13）故仅 ImportError 路径触发，但属潜在医疗安全隐患。
- 修法：回退法应返回 `None` + `insufficient_data`（与主路径失败口径一致），或至少对窗口测量值显式标注 `"estimated"/"fallback"` 而非当作真实测量；PR 固定 200ms 尤其不可作为测量输出。

### 🟠-6 阈值判据是“逐类 F1 最大”，与背景所述“Youden 阈值”不一致
- 位置：`src/ecg_models/trainer.py:480-487`
- 证据：`fit_thresholds` 路径逐类 `precision_recall_curve` 后取 `f1_curve = 2·P·R/(P+R)` 的 argmax：
  ```python
  f1_curve = 2 * prec[:-1] * rec[:-1] / (prec[:-1] + rec[:-1] + 1e-8)
  best_idx = int(np.argmax(f1_curve))
  best_thresh = float(thresh[best_idx])
  ```
  这是 F1 最大阈值，不是 Youden 指数 `J = Se + Sp − 1 = TPR + TNR − 1`。若论文/背景声称“逐类 Youden 阈值取自验证集”，则实现口径与表述不符，影响论文结论可靠性；需统一（改实现为 Youden，或改表述为 F1-max）。
- 修法：确认论文口径后二选一；若确为 Youden，用 `sensitivity + specificity − 1` 逐阈值最大化（可由 PR 曲线的 P/R 反推 TPR/TNR，或直接对 prob 阈值扫描）。

### 🟠-7 验证集阈值与 `_fitted` 未随检查点持久化 → best_model.pt 无法复现测试指标
- 位置：`src/ecg_models/trainer.py:620-635`（`_save_checkpoint` 仅存 epoch/model_state_dict/best_metric）；`load_checkpoint:638-655` 不恢复 `val_thresholds`；`anomaly_detector.py:65,109-111`（`_fitted` 不入 state_dict）
- 证据：`_save_checkpoint` 保存的字典只有 `epoch / model_state_dict / best_metric` 三个键；`evaluate()` 测试评估需要 `trainer.val_thresholds`，但 `load_checkpoint` 加载后 `self.val_thresholds` 仍为 `None`，测试评估只能退回 0.5 默认并告警，无法从 `best_model.pt` 复现论文报告指标。实测 `_fitted` 确认不在 `state_dict()` 中（`'_fitted' in det.state_dict() == False`）；`threshold` buffer 本身能持久化，但加载后 `is_anomaly` 仍抛 `RuntimeError("必须先调用 fit_threshold()")`。
- 修法：`_save_checkpoint` 一并写入 `val_thresholds`（与 `_fitted`/`threshold`），`load_checkpoint` 恢复之；否则在产物说明中明确“阈值需在验证集重新确定”。

### 🟡-1 Net1D 默认返回 logits 而非特征，与其它 backbone 接口不一致
- 位置：`src/ecg_models/backbone/ecgfounder_net1d.py:377-399`（`return_features` 默认 False）、`:374`（`feature_dim`）
- 证据：`Net1D.forward` 默认只返回 `dense(deep_features)`（logits）；实测 `m(x)` 返回 `(2,27)`，需 `return_features=True` 才返回 `(logits, features)`。其它四个 backbone 均直接返回特征向量。若把 Net1D（未开 `return_features`）当 `ECGAnomalyDetector`/`ArrhythmiaClassifier` 的 backbone，`feature_dim=1024` 但前向产出 27 维 → 编码头 Linear 形状不匹配崩溃。此外 `ecg_models/__init__.py` 未导出 `Net1D`（ECGFounder 的 MLP 头在 `agent/tools/ecgfounder_classifier.py` 里单独实例化）。
- 修法：为 Net1D 增加“作为特征 backbone”的明确入口（如 `as_backbone()` 或默认 `return_features=True` 并在分类器层加投影），并在 `__init__.py` 导出。

### 🟡-2 QT 死常量 + 命名误导（450/460 实为 QTc 上界）
- 位置：`src/ecg_models/feature_extraction/qt_analyzer.py:33-38`
- 证据：`QTC_NORMAL_UPPER = 440` 全文仅定义、从未引用（grep 确认）；`PR_NORMAL_RANGE = (120,200)` 同样未被用于解读。`QT_NORMAL_UPPER_MALE=450 / FEMALE=460` 命名含 “QT” 却实际作为 **QTc** 正常上界传给 `_interpret_qt`（`:118`），与注释（`:149`）一致但命名易误导。
- 修法：删除死常量；将 450/460 重命名为 `QTC_NORMAL_UPPER_MALE/FEMALE` 或在 `_interpret_qt` 内注释明确。

### 🟡-3 `evaluate(fit_thresholds=True)` 无强制防泄漏护栏
- 位置：`src/ecg_models/trainer.py:419-427, 472-487`
- 证据：`fit_thresholds` 是公开参数，docstring 声明“仅允许 fit 内部对验证集现算”，但代码无任何运行时校验——对 `test_loader` 调用 `evaluate(test_loader, fit_thresholds=True)` 会静默在测试集上现算阈值（样本内乐观，数据泄漏），仅靠约定约束。
- 修法：将 `fit_thresholds` 收敛为私有（或加 `loader_name`/白名单断言），测试集路径只允许显式传入 `thresholds`。

### 🟡-4 `detect_multi_lead` 共识投票偏向 Lead II，agreement 口径模糊
- 位置：`src/ecg_models/feature_extraction/r_peak_detector.py:188-196`
- 证据：投票只遍历 `all_peaks[0]`（第一个目标导联，默认 Lead II）的峰；某个真峰若 Lead II 漏检但 V1/V5 都检出，不会被纳入共识（有偏）。`agreement = len(consensus) / max(len(p) for p in all_peaks)` 的分母是“单导联最大峰数”，与注释“共识投票”语义不符（非跨导联一致率）。另：`detect()` 的 insufficient/噪声两个早退分支（`:85-92`、`:107-114`）不写 `self.last_result`，与主路径（`:156`）不一致。
- 修法：对 `set.union(*all_peaks)` 投票；`agreement` 改为按导联投票命中率定义；早退分支同步维护 `last_result`。

### 🟡-5 “Challenge Score” 与官方 PhysioNet 2020 指标需核对
- 位置：`src/ecg_models/trainer.py:533-590`
- 证据：实现为 `(F_beta + G_beta)/2`，其中 `G_beta` 是 NDCG 风格（按 `probs` 排序，DCG/IDCG）。而 PhysioNet/CinC 2020 官方评分是基于 27×27 加权评分矩阵的修正 F-measure，并非 `(Fβ + NDCG)/2`。若论文以“官方 Challenge 指标”名义报告该值，口径需与官方定义核对（本项为口径提示，未逐条对照官方公式）。
- 修法：与官方 2020 计分函数逐项对齐或明确标注“项目自定义 Challenge Score”。

### 🟡-6 特征失败标志双轨制（insufficient 与 error 不统一）
- 位置：`feature_bank.py:86-99`；`r_peak_detector.py`（`insufficient`）/ `hrv_analyzer.py`（`insufficient`）/ `qt_analyzer.py:207`（`error`）
- 证据：R 峰/HRV 用 `insufficient: True/False`，QT 用 `error: "insufficient_data"`；`FeatureBank.extract_all` 里 HRV 的 `_empty_result` 会 `update` 进 `insufficient=True`，而 QT 失败只留下 `error` 键，下游判断失败需同时看两个键，易漏。
- 修法：统一为单一失败标志（如 `insufficient: bool` + 可选 `error_reason: str`），三模块一致。

### 💡-1 噪声守卫阈值以 mV 为量纲，z-score 归一化输入下失效
- 位置：`r_peak_detector.py:104-116, 264`（`np.ptp(filtered) < 0.15`）
- 证据：守卫假设输入为 mV 量纲（QRS 带通后峰峰值 ≥0.15mV）；对 z-score 归一化输入（std≈1）峰峰值 ~6-10 恒不触发，噪声/导联脱落无法被识别（代码注释已自述该局限）。建议在守卫前检测输入量纲或改用统计判据（如带通后峰峰/噪声本底比值）。

### 💡-2 InfoNCE 在 batch_size=1 时退化为 0 损失
- 位置：`trainer.py:216-238`
- 证据：`B=1` 时 `negatives = sim[~mask].view(2, 0)`，`logits` 只有正类一列，`cross_entropy` 对单类恒为 0（无负样本，无梯度信号）。建议对比训练断言 `batch_size ≥ 2` 并告警。

### 💡-3 `_interpret_qt` 在 rr_ms=0（重复 R 峰）时把 QTc=0.0 判为 normal
- 位置：`qt_analyzer.py:138-157`
- 证据：`_qtc_bazett` 在 `rr_ms<=0` 返回 0.0（防除零），随后 `_interpret_qt(qt_ms, 0.0, upper)` 走 `qtc_ms > 500? 否 / qt_ms<300? 否 / qtc_ms>upper? 否` → `"normal"`。重复 R 峰导致 rr_ms=0 的病理边界下会被解读为正常。建议 `rr_ms<=0` 时 `_compute_results` 直接走失败显式化，而非给 QTc=0。

## 阳性结论（实测验证正确的性质）

1. **语法/可导入**：全部 12 个源文件 `py_compile` exit 0；`src/ecg_models/__init__.py` 导出与实现一致。
2. **backbone 前向与 `feature_dim` 一致**：ResNet1D-18 → `(2,512)`、xResNet1D-101 → `(2,512)`、InceptionTime → `(2,128)`、ECGTransformer → `(2,d_model)`；Net1D `return_features=True` 特征 `(2,1024)` 且 `feature_dim=1024 == dense_in == 末级通道数`，SE 通道加权 `einsum('abc,ab->abc')` 形状正确。
3. **AsymmetricLoss 数值稳定且公式正确**：极端 logits（±1000）经 clamp 后无 NaN（实测 loss≈9.6e-23）；负类概率偏移用减法在概率空间实现、聚焦项 `max(p−m,0)^γ` 与 Ben-Baruch 论文一致；`FocalLoss` 的 `pt=exp(−bce)` 推导正确。
4. **异常检测器**：`threshold` 经 `fit_threshold` 赋值后仍是注册 buffer（`named_buffers()` 含 threshold，可入 state_dict）；未拟合时 `is_anomaly` 显式抛错；VAE KL 与重参数化公式正确。
5. **R 峰检测**：合成 ECG 实测 11 峰、HR=72.3、`normal rate (regular)`；纯噪声被 5-15Hz 带通守卫正确判 `insufficient=True`（即使误检出 30 峰也不误报心动过速）；`pan_tompkins→pantompkins` 版本名映射与 `VALID_METHODS` 校验正确。
6. **HRV 时域/非线性**：RR<3 或过滤后 <2/3 返回 `None`+`insufficient`（不伪造 0）；SDNN/RMSSD/pNN50/CV 无除零；样本熵 `B==0` 返回 None、模板数 `N−m+1` 正确。
7. **QT 主路径**：中位数聚合稳健；Bazett/Fridericia/Framingham 三公式正确、`rr_ms>0` 防除零；`_safe_wave_index` 正确处理 `np.float64/np.nan`（`int(nan)` 不再崩）；失败返回 `None` 而非 0。
8. **FeatureBank.to_vector**：缺失键与 None 值 → `NaN`（不静默填 0 冒充测量）；`feature_dim=22` 与 `_default_feature_keys` 顺序一致。
9. **Trainer 口径**：InfoNCE 负样本掩码同时剔除自身与正样本对；阈值仅在验证集 `fit_thresholds` 确定，测试集未传阈值时告警并退回 0.5（不现算，防泄漏）；早停回填 best-val 权重并同步快照 best 阈值；macro AUC/mAP 均按 `0<sum<len` 过滤一致；`safe_torch_load` 加载；`challenge_score ∈ [0,1]`（实测 0.48/0.70）；label smoothing 注释与公式一致（`1−ε/2` / `ε/2`）。
10. **ECGTransformer**：`compute_output_length(4096,49,24)=171` 正确；手写注意力仅用 Linear+matmul+softmax，避免 NPU 融合算子回退；正弦位置编码在 `max_len` 内形状正确。
