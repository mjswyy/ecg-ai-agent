## 阳性结论

1. **主结果可复现**：用当前 `classification.py` + 当前 `test_features.npy` + 当前 `mlp_head.pt` 只读复算，`macro_auc=0.9456`、`mAP=0.5822`、参与类 27，与 `outputs/ecgfounder_mlp/metrics.json` 精确一致；`metrics.json` 的 CI `[0.9393,0.9519]` 与 `per_source_auc.json` 的 overall CI 完全一致（同一 seed=42 口径）。
2. **metrics 模块阈值口径正确**：`evaluate()` 未传 thresholds 时告警并用 0.5（2E-O7），不再在评估集现算 Youden；`eval_per_class.py`/`eval_per_source.py` 均显式用验证集阈值，与主评测一致。
3. **mAP 类过滤正确**：`classification.evaluate()` 仅对 `0<sum<len` 类取 AP 平均（4H-ORANGE-1）；当前 27 类全非退化，复算 mAP=0.5822 与产物一致。
4. **topk_hits 正确处理无标签样本**：分母只计有正类样本，与 `metrics.json` top1/top3/top5 口径一致。
5. **bootstrap 可复现**：`macro_auc_with_ci` 固定 `RandomState(seed)`，CI 可复现；宏平均前正确跳过全 0/全 1 类。
6. **mlp_head 结构重建正确**：`eval_per_class.py`/`eval_per_source.py` 的 `load_head` 重建（1024→512→27 + ReLU + Dropout）与 `mlp_head.pt` 的 `net.0/net.3` 形状 (512,1024)/(27,512) 完全吻合，`net.` 前缀剥离逻辑正确。
7. **per_source 分组正确**：长前缀优先匹配（`cpsc_2018_extra` 先于 `cpsc_2018`），各源 n 之和 516+131+946+7+2152+2 = 3754 = overall，无未匹配 id 被静默丢弃（且代码对未匹配显式告警）。
