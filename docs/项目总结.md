# 面向心电图分析的情境感知与自主交互学习的 AI Agent — 项目总结

> 2026年7月-8月 | 华为云 ModelArts + Ascend NPU 910B

---

## 一、项目概述

构建一个 LLM 驱动的 AI Agent，输入 12 导联心电图和患者信息，自动输出诊断报告、推理链和标注波形图。核心创新：让 AI Agent 自主规划诊断步骤，调用各种 ECG 分析工具，自我反思验证结果。

### 四层架构

```
Phase 4: AI Agent 框架 ← ReAct (规划→工具调用→自反思→诊断报告)
Phase 3: 情境建模      ← ECG + 临床文本 + 元数据 → 多模态融合
Phase 2: ECG 基础模型  ← 4 个骨干 + SimCLR 预训练 + 集成
Phase 1: 数据管道      ← 43K 条 ECG → 预处理 → 增强 → Dataset
```

---

## 二、各阶段成果

### Phase 1：数据管道 ✅

- 43,101 条 12 导联 ECG，(12, 4096) float32，~4 GB
- 6 数据源（CPSC 2018、Georgia、PTB、PTB-XL、INCART）
- 27 类 SNOMED CT 标签，42 个等价码，覆盖率 99.6%
- 6 步预处理：SOS 带通滤波 → 陷波 → resample_poly → 分段对齐 → z-score → 5σ 裁剪
- 6 种 ECG 专用增强：基线漂移、高斯噪声、时间扭曲、幅度缩放、导联丢失、片段打乱

### Phase 2：ECG 基础模型 ✅

| 模型 | test AUC | Top-5 | 参数量 | 训练时间 | 方法 |
|------|:---:|:---:|------|------|------|
| InceptionTime（基线） | 0.590 | — | 291K | 40 min | 从头训练 |
| xResNet1D-101 | 0.791 | 92.7% | 7.6M | 83 min | 从头训练 |
| ECG Transformer | 0.808 | 92.8% | 6.5M | 85 min | 手写 attention NPU 适配 |
| **SimCLR xResNet** | **0.841** | **95.3%** | 7.6M | 3 h | 自监督预训练→微调 |
| **集成 (3-model)** | **0.850** | 94.8% | ~21M | — | 概率平均 |

**关键经验**：
- BCE + 强正则化（dropout 0.3, wd 1e-3, label_smoothing 0.1）是最佳组合
- AsymmetricLoss 与 Label Smoothing 冲突
- 大模型 lr=5e-5（非直觉的 1e-5）
- SimCLR 对比预训练是本项目最大单次提升（+0.050 AUC）
- CANN 8.0.0 不支持 Transformer 融合算子，手写 attention 解决

### Phase 3：情境建模 ✅

**多模态融合架构**：
```
ECG 信号 → ECGFounder Backbone (冻结) → 1024维
                                                ↘
PTB-XL 报告 → PubMedBERT (冻结) → 768维  → CrossAttention Fusion → 分类头 → 27类
                                                ↗
患者信息 → Metadata Encoder → 128维
```

| 模型 | test AUC |
|------|:---:|
| 纯 ECG 信号集成 | 0.850 |
| ECGFounder 线性探针 | 0.897 |
| **多模态融合 (ECG + Text)** | **0.971** |

**关键发现**：ECG 信号 + 临床文本（PTB-XL 医生报告）的交叉注意力融合，将 AUC 从 0.897 提升到 0.971——临床文本贡献了 +0.074。

### Phase 4：AI Agent ✅

**ReAct 推理链**：R峰检测 → HRV分析 → QT间期 → 心律失常分类 → 异常检测 → 诊断报告

- 100 条 ECG 端到端评估：**Top-5 命中率 94%**
- 100% 工具调用成功率
- Agent 推理链与模型直接输出精度无显著差距（-2.7% Top-1）
- Agent 提供完整的可解释推理过程

### 外部基准：ECGFounder ✅

- 下载 NEJM AI 2025 预训练模型（150 类，10M+ ECG 预训练）
- 线性探针：AUC 0.897（冻结特征 + 逻辑回归）
- 150 类综合分析工具：`scripts/analyze_ecg.py`

## 五、核心技术决策

| # | 决策 | 理由 |
|---|------|------|
| 1 | SOS 滤波替代 ba 形式 | 数值更稳定 |
| 2 | resample_poly 替代线性插值 | 保留 QRS 高频形态 |
| 3 | 填充感知归一化 | 零填充不稀释统计量 |
| 4 | BCE + 强正则化 | ASL 与 Label Smoothing 冲突 |
| 5 | 大模型 lr=5e-5 | 避免尖锐极小值过拟合 |
| 6 | SimCLR 预训练 | 单模型 +0.050 AUC |
| 7 | ECGFounder 作为 ECG 编码器 | 10M+ 预训练特征远优于从头训练 |
| 8 | 冻结 backbone + 仅训练融合层 | 15K 文本数据不够微调 15M 参数 |
| 9 | 手写 attention 替代 nn.MultiheadAttention | CANN 8.0.0 NPU 算子适配 |
| 10 | Transformer FP32 | 手写 attention 在 AMP 下 LossScale 溢出 |

## 六、已知局限

- **稀有类**：窦性心律失常（43 样本）几乎无法预测
- **相近疾病混淆**：房颤 vs 房扑、左/右束支阻滞互报
- **文本仅 PTB-XL**：15K 条报告，未覆盖全部 43K ECG
- **单数据中心**：PhysioNet 2020 为主，缺少跨数据集验证
