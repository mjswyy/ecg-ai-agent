## 三、关键经验

### 3.1 损失函数

- **BCE + 强正则化** 是 27 类不平衡任务的最佳组合
- AsymmetricLoss 与 Label Smoothing 冲突，大模型上会崩溃
- 默认用 `--loss bce`

### 3.2 学习率

| 模型 | 推荐 lr | 说明 |
|------|------|------|
| InceptionTime (291K) | 1e-4 | 小模型用大 lr |
| 大模型 (6-8M) | **5e-5** | 1e-5 会陷入尖锐极小值 |

### 3.3 正则化

| 参数 | 推荐值 | 作用 |
|------|------|------|
| `weight_decay` | 1e-3 | L2 正则化 |
| `dropout` | 0.3 | 防过拟合 |
| `label_smoothing` | 0.1 | 防过自信 |
| `augment_prob` | 0.8-1.0 | 数据增强 |

### 3.4 NPU 兼容性

- **AMP + CNN**: 可用（xResNet 无 NaN）
- **AMP + Transformer**: 不可用（手写 attention 在 FP16 下 LossScale 膨胀）
- **Transformer FP32**: 可用（约慢 20-30% 但数值安全）
- **Transformer 算子**: CANN 8.0.0 不支持 nn.MultiheadAttention 融合算子，需手写 attention

### 3.5 SimCLR 预训练

- SimCLR 是本项目最大单次提升（+0.050 AUC）
- 50 epochs 预训练 + 50 epochs 微调 约 3 小时
- InfoNCE loss 收敛到 ~0.70 是正常的（不归零）
- 必须用 `--no-amp`（FP16 下相似度矩阵不稳定）

## 四、Notebook 操作流程

### 从头训练

```bash
cd /home/ma-user/work/ecg-ai-agent && git pull origin main

# 同步数据
python -c 'import moxing as mox; mox.file.copy_parallel("obs://ecg-ai-agent/data/physionet2020/processed/", "/cache/data/")'

# 校验数据
python -c '
import os, json
processed = "/cache/data/processed"
for split in ["train", "val", "test"]:
    with open(f"{processed}/{split}_manifest.json") as f: data = json.load(f)
    data["files"] = [r for r in data["files"] if os.path.exists(os.path.join(processed, r["signal_file"]))]
    data["count"] = len(data["files"])
    with open(f"{processed}/{split}_manifest.json", "w") as f: json.dump(data, f, indent=2)
'

# 训练
python scripts/train_simclr.py --backbone xresnet1d_101 --device auto --no-amp --output-dir /cache/output/simclr_xresnet
```

### 保存结果

```bash
python -c 'import moxing as mox; mox.file.copy_parallel("/cache/output/模型名/", "obs://ecg-ai-agent/outputs/模型名/")'
```
