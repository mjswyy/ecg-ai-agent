## 四、详细设计

### Phase A：评估体系升级

#### A1：Bootstrap CI 逐类置信区间

**借鉴**：ECGFounder + ecg_ptbxl_benchmarking

```python
# 核心逻辑
for _ in range(n_bootstrap=1000):
    idx = np.random.choice(N, N, replace=True)
    aucs.append(roc_auc_score(labels[idx], probs[idx]))
ci_low, ci_high = np.percentile(aucs, [2.5, 97.5])
```

**输出**：每类 AUC ± 95% CI，宏平均 AUC ± 95% CI

#### A2：逐类 Youden 最优阈值

**借鉴**：ECGFounder（替代当前 P-R curve F1 极大点）

```python
# Youden's J = TPR - FPR
fpr, tpr, thresholds = roc_curve(y_true, y_prob)
j_scores = tpr - fpr
best_threshold = thresholds[np.argmax(j_scores)]
```

**优势**：Youden 同时考虑敏感度和特异度，比单看 F1 更均衡。

#### A3：改进分类头为 AdaptiveConcatPool1d

**借鉴**：ecg_ptbxl_benchmarking 的 `create_head1d`

```python
# 当前：AdaptiveAvgPool1d(1) → Flatten → Linear
# 改进：AdaptiveAvgPool1d(1) + AdaptiveMaxPool1d(1) → Concat → Linear
class AdaptiveConcatPool1d(nn.Module):
    def forward(self, x):
        return torch.cat([x.mean(dim=-1), x.max(dim=-1).values], dim=-1)
```

**预期收益**：avg+max 拼接保留更多信息，+0.005-0.01 AUC。

#### A4：三模型完整对比 + McNemar 检验

**借鉴**：automatic-ecg-diagnosis

输出表格：

| 模型 | macro_auc | macro_f1 (最优阈值) | mAP | Top-5 | 参数 |
|------|:---:|:---:|:---:|:---:|------|

### Phase B：Phase 3 多模态改造

#### B1：PatternLabeler 结构化 PTB-XL 报告

**借鉴**：ECG-FM 的 PatternLabeler

**输入**：`"sinus rhythm. incomplete right bundle branch block. minor non-specific t wave flattening."`

**输出**：

**流程**：

2. 用其 18 类标签体系（或适配为 27 类）处理 15,110 条 PTB-XL 报告
3. 输出 `ptbxl_structured_labels.json`

#### B2：修复 Phase 3 代码 3 个 bug

| Bug | 修复 |
|-----|------|
| `SimpleECGProjector` 缺 `feature_dim` | 添加 `@property feature_dim` |
| `LateFusion` 零张量维度错误 | `zeros(B, meta_dim)` 而非 `zeros(B, output_dim)` |
| `ECGTokenizer` 无法接入下游 | 添加 `encode_to_features()` 返回池化特征 |

#### B3：基于 torch_ecg 模块化架构

**借鉴**：torch_ecg 的 `ECG_CRNN` 管道模式

```
ECG_CRNN 管道:
  CNN Backbone（xResNet / ECG Transformer）
    → Attention（SE / Cross-Attention）
    → Fusion（Gate / Concat / Cross-Attn）
    → Global Pooling
    → Classifier MLP
```

**多模态扩展**：

```
ECG信号 (B, 12, 4096)
    → CNN Backbone → ECG Features (B, D_ecg)
    
文本报告 (B, "sinus rhythm...")
    → PubMedBERT → Text Features (B, 768)
    
元数据 (age, sex, source)
    → MetadataEncoder → Meta Features (B, 128)

    → CrossAttentionFusion / GatedFusion
    → Global Pooling
    → Classifier → (B, 27) logits
```

### Phase C：预训练增强

#### C1：SimCLR 对比预训练

利用全部 43,101 条 ECG 信号（无需标签），训练 backbone 学习信号表示。

**预期**：单模型 +0.02-0.03 AUC。

#### C2：RLM 导联掩码预训练

**借鉴**：ECG-FM

训练时随机 mask 1-3 个导联（置零），强迫模型学会从残缺导联中推断全局特征。

**关键**：能使模型对导联缺失鲁棒（临床常有电极脱落）。

```python
# RLM: Random Lead Masking
def random_lead_mask(ecg, n_mask=2):
    """ecg: (B, 12, L), 随机选2个导联置零"""
    mask_idx = torch.randperm(12)[:n_mask]
    ecg[:, mask_idx] = 0
    return ecg
```
